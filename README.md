# Gerador-Pavimentos-CAD
Aplicação desenvolvida em Python para automatizar a criação de desenhos técnicos de pavimentos em formato DXF. Voltada a engenheiros e projetistas, permite configurar alturas, espessuras de lajes, níveis e cotas, facilitando a elaboração de projetos e reduzindo tarefas repetitivas.
Inicie o aplicativo e escolha qual medida irá utilizar (piso à laje ou piso à piso), coloque a quantidade de pavimentos e coloque as medidas! O arquivo dxf será gerado automáticamente após terminar de colocar as medidas no aplicativo.
